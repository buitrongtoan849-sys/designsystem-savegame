04. Semantic Token — Background

Đây là token dùng thật trong UI. Mỗi token có mã màu riêng cho Dark và Light.

bg-primary
Dùng: nền toàn app
Dark: #020B17
Light: #F8FAFC
bg-secondary
Dùng: section phụ, list item
Dark: #0F172A
Light: #FFFFFF
bg-card
Dùng: card, form, block
Dark: #1E293B
Light: #FFFFFF
bg-elevated
Dùng: popup, dropdown, disabled bg
Dark: #334155
Light: #F1F5F9

05. Semantic Token — Text

Text token giúp mày không phải chọn màu chữ thủ công từng màn hình.

text-primary
Dùng: title, text chính

Light: #0F172A
text-secondary
Dùng: mô tả, text phụ

Light: #334155
text-muted

Light: #64748B
text-disabled

Light: #94A3B8

08. Cách dùng trong dự án thật

Background app: var(--bg-primary)

Card: var(--bg-card)

List item: var(--bg-secondary)

Popup / dropdown: var(--bg-elevated)

Title: var(--text-primary)

Mô tả: var(--text-secondary)

Caption: var(--text-muted)

Border card/input: var(--border-default)

Focus input: var(--border-focus)

Nút chính: var(--brand-green) hoặc var(--brand-gradient)
