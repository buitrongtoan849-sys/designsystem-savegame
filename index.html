04. Semantic Token — Background

Đây là token dùng thật trong UI. Dark Mode đã tối hơn bản trước.

bg-primary
Dùng: nền toàn app
Dark: #010713
Light: #F8FAFC
bg-secondary
Dùng: section phụ, list item
Dark: #07111F
Light: #FFFFFF
bg-card
Dùng: card, form, block
Dark: #0B1626
Light: #FFFFFF
bg-elevated
Dùng: popup, dropdown, disabled bg
Dark: #122033
Light: #F1F5F9

07. Button Usage Rule

Quy định để không bị loạn giữa nút Gradient và nút Primary Green.

Hero Button
Màu: Gradient
Dùng: CTA quan trọng nhất, onboarding, setup tháng
Primary Button
Màu: #22C55E
Dùng: lưu, thêm, xác nhận, cập nhật
Secondary Button
Màu: outline cyan
Dùng: xem chi tiết, quay lại, hành động phụ
Danger Button
Màu: #EF4444
Dùng: xóa, reset, hành động nguy hiểm

09. Cách dùng trong dự án thật

Card: var(--bg-card)

List item: var(--bg-secondary)

Popup / dropdown: var(--bg-elevated)

Title: var(--text-primary)

Mô tả: var(--text-secondary)

Caption: var(--text-muted)

Border card/input: var(--border-default)

Focus input: var(--border-focus)

Hero Button: var(--brand-gradient)

Primary Button: var(--brand-green)
